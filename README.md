# Performing Arts Meta POC

Streams the SpatialGen Widevine-encrypted HLS sample to a secure stereo 180-degree
video surface on Meta Quest 3/3S. The app starts playback after the surface is ready.

## Configure the API key

Add this to the root `local.properties` file (ignored by Git), alongside `sdk.dir`
if you use that property:

```properties
SPATIALGEN_API_KEY=your-spatialgen-app-key
```

Alternatively, set the `SPATIALGEN_API_KEY` environment/Gradle property, or assign
the key directly to `SpatialGenPlaybackConfig.API_KEY` in
`app/src/main/java/com/meta/spatial/samples/spatialvideosample/SpatialGenPlaybackConfig.kt`.
Gradle property > environment > local.properties is the build-time precedence.
Rebuild after changing the key. A missing key is shown in the headset controls.
The stream and license URLs are in the same config file.

An app key compiled into an APK can be extracted. For production, place a privileged
SpatialGen key behind your authenticated backend license proxy; adapt the callback
to authenticate the viewer to that proxy.

## License exchange

The implementation follows the [SpatialGen Widevine guide](https://docs.spatialgen.com/security/widevine-drm/):

1. Media3 reads Widevine PSSH initialization data from the HLS media playlists.
2. `KeyIdMediaDrm` extracts the public 16-byte KID from that metadata and associates
   it with the exact request generated by `FrameworkMediaDrm` on the headset.
3. `SpatialGenLicenseClient` posts JSON to `https://drm.spatialgen.com/widevine/license`:

   ```http
   Content-Type: application/json
   X-SPATIALGEN-APPKEY: <your app key>
   ```

   ```json
   {
     "key_id": "<hyphenated UUID from PSSH>",
     "license_challenge": "<base64 of the device CDM challenge>"
   }
   ```

4. The JSON response's `license` field is decoded from base64 and returned to
   Media3, which passes it to the device CDM. Decryption stays inside the DRM path.

The sample's public KID observed during implementation was
`302f80dd-411e-4886-bca5-bb1f8018a024`; it is a test fixture only, never a playback
constant. PSSH versions 0 and 1 are supported. Each DRM request must identify one
unique KID; missing or ambiguous metadata fails explicitly. Multiple sessions allow
distinct audio/video keys or key rotation when each session's PSSH identifies one KID.
KID association is retained for retries and session renewal. Offline licensing and
legacy `com.widevine` JSON HLS signaling are outside this sample's scope.

Only the license request receives the app key. CDN fetches and standard CDM
provisioning use separate paths. License requests have timeouts, bounded response
sizes, no redirects, and no sensitive payload logging. Permanent license failures
stop; transient failures use Media3's bounded retry policy. Press play to retry a
failed playback attempt.

## Secure video on Quest

The video `MediaPanelSettings` uses `MediaPanelRenderOptions(isDRM = true)` with
direct `PanelSceneObject` surface output, following
[Meta's protected-content guide](https://developers.meta.com/horizon/documentation/spatial-sdk/spatial-sdk-2dpanel-drm/).
The old texture-sampling reflection/shadow mesh was removed from the video path.
The stereo `LeftRight` 180-degree presentation is preserved. No local video files,
storage permissions, or thumbnail extraction are needed.

## Build and headset verification

Use JDK 17, Android SDK Platform 35 / Build Tools 35, and the project's Gradle wrapper.
The existing scene export also requires Meta Spatial Editor configured for the project.

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.spectrum.spectrumsports/.SpatialVideoSampleActivity
```

Test with a valid SpatialGen key on a connected Quest 3:

- Confirm the sample starts automatically with audio and correct stereo projection.
- Check pause/play, seeking, repeat, headset sleep/resume, and app exit/relaunch.
- Confirm protected video is absent from screenshots/casting.
- With an invalid key, confirm a license error appears and no endless retries occur.
- Inspect `adb logcat -s SpatialVideoSampleActivity ExoPlayerImpl MediaCodec` for
  playback/decoder diagnostics. Do not add logging of keys, challenges, or licenses.

The sample advertises 7680x3840 HEVC Main 10 / PQ at 90 fps, with renditions around
40, 60, and 80 Mbps. Media3 selects the rendition. Network throughput and the
headset's secure decoder support must be checked on-device; obtaining a license
alone does not verify this video format can decode successfully.

Unit tests exercise the actual sample PSSH, version 1 metadata, duplicate/malformed/
ambiguous KIDs, the JSON/header/base64 exchange, size limits, and HTTP failures.
They do not emulate the headset CDM or prove real license acquisition/playback.
